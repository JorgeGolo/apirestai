Bienvenido

AnotherBrain es una herramienta diseñada para generar y almacenar chats de ChatGPT dinámicamente, lo que permite manejar múltiples conversaciones de manera ordenada y sin interrupciones. Está integrado con la API de ChatGPT, que proporciona respuestas inteligentes y personalizadas en tiempo real.

Cómo funciona

  • Desde el menú puedes crear un nuevo chat dándole un nombre, eligiendo un modelo de entre los disponibles y describiendo el rol que tendrá. El chat se añadirá a la lista. Dentro del mismo se puede interactuar con la API de Groq.

  • Un usuario logueado con su cuenta de Google tendrá almacenados sus chats, preguntas y respuestas. El sistema sólo almacena un id aleatorio de usuario que permite su autenticación, pero no se guarda el correo electrónico ni ningún otro dato personal.

  • Desde la lista de chat el usuario puede editar las características del chat o borrarlo de la base de datos.

  • Cada par pregunta/respuesta tiene un icono de una paplera junto su fecha de creación. Pulsando este icono el par será borrado de la base de datos.

  • Desde la zona de usuario, es posible borrar todos los datos del usuario.
